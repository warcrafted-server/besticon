## 0.1.0 (first release / primera versión)

**English**
- Instant bilingual (English + Spanish) icon search by name, ID and path, ignoring accents, capitals and plurals.
- Catalog of 27,714 icons read from the WoW Forever client, with readable names.
- Native-looking window: search box, category filter, scrollable icon grid with adjustable size, and info panel with preview, ID and path (copyable).
- Favorites (right-click), history of the last 40 icons, and All / Favorites / History tabs.
- Macro helper: selects the chosen icon in the standard macro icon picker.
- English and Spanish interface. Commands: /bi and /besticon.

**Español**
- Búsqueda instantánea bilingüe (español + inglés) por nombre, ID y ruta, sin tildes, mayúsculas ni plurales.
- Catálogo de 27 714 iconos leído del cliente de WoW Forever, con nombres legibles.
- Ventana de aspecto nativo: buscador, filtro de categorías, cuadrícula con tamaño ajustable y panel de información con vista previa, ID y ruta copiables.
- Favoritos (clic derecho), historial de 40 y pestañas Todos / Favoritos / Historial.
- Ayuda para macros: selecciona el icono elegido en el selector de iconos de macros.
- Interfaz en español e inglés. Comandos: /bi y /besticon.

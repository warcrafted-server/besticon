## 0.3.0 — Button in the macro window / Botón en la ventana de macros

**English**

- New: a **Best Icon** button in the main macro window (**/macro**), in the bottom row between *Delete* and *New*. One click opens the finder, with no need to open the icon picker first.
- **/bi debug** now also reports the state of that button.

**Español**

- Nuevo: un botón **Best Icon** en la ventana principal de macros (**/macro**), en la fila inferior entre *Eliminar* y *Nuevo*. Con un clic se abre el buscador, sin tener que abrir antes el selector de iconos.
- **/bi debug** informa también del estado de ese botón.

## 0.2.0 — Search by intent / Búsqueda por intención

**English**

- New: search by intent. Words like "thanks", "hello", "welcome", "help", "party", "love", "cheers", "victory", "danger", "death", "peace", "music" or "letter" now lead to the icons that represent them, even when no icon is named after the word. It works in English and Spanish ("gracias", "saludo", "ayuda"...).
- Example: **thanks** or **gracias** shows gifts, bouquets, flowers and roses.

**Español**

- Nuevo: búsqueda por intención. Palabras como «gracias», «saludo», «bienvenida», «ayuda», «fiesta», «amor», «brindis», «victoria», «peligro», «muerte», «paz», «música» o «carta» llevan ahora a los iconos que las representan, aunque ningún icono se llame así. Funciona en español e inglés («thanks», «hello», «help»...).
- Ejemplo: **gracias** o **thanks** muestran regalos, ramos, flores y rosas.

## 0.1.1 — Visual polish / Ajustes visuales

**English**

- Grid icons now use the game's own button frame, and the selected icon is marked with the classic gold frame and glow.
- The **Best Icon** button moved into the bottom bar of the macro icon picker, matching the height and row of the native buttons.
- Default icon size is now 40.
- Fixed: the selection highlight was invisible because of a bad texture path.
- New: **/bi debug** prints the state of the picker button.

**Español**

- Los iconos de la cuadrícula llevan ahora el marco de los botones del juego, y el icono seleccionado se marca con el marco dorado y el resplandor clásico.
- El botón **Best Icon** pasa a la barra inferior del selector de iconos de macros, con la misma altura y fila que los botones nativos.
- El tamaño de icono por defecto es 40.
- Corregido: el resaltado de la selección era invisible por una ruta de textura mal escrita.
- Nuevo: **/bi debug** muestra el estado del botón del selector.

## 0.1.0 — First release / Primera versión

**English**

- Visual icon finder for WoW Forever: 27,714 icons from the client, each with a readable name.
- Bilingual search (English and Spanish), by ID or by texture path; accents, capitals and plurals do not matter.
- Visual grid, info panel with ID and path, categories, favorites and history.
- Macro helper: select the icon in the standard picker; you confirm in the macro window.
- Commands: **/besticon** and **/bi**.

**Español**

- Buscador visual de iconos para WoW Forever: 27 714 iconos del cliente, cada uno con nombre legible.
- Búsqueda bilingüe (español e inglés), por ID o por ruta; ignora tildes, mayúsculas y plurales.
- Cuadrícula visual, panel de información con ID y ruta, categorías, favoritos e historial.
- Ayuda para macros: selecciona el icono en el selector estándar y tú confirmas en la ventana de macros.
- Comandos: **/besticon** y **/bi**.
